# Pune AQI Monitor (IoT Sensor + Cloud + Visualization Simulation)

## How to Run
1. Extract this ZIP folder.
2. Double-click `index.html` to open it in any modern web browser (Chrome, Edge, Firefox, Safari).

## Included Pages
- **Overview**: Live US EPA AQI readout, station switcher (Shivajinagar, Hinjewadi, Hadapsar), and real-time telemetry trend chart.
- **Pune Map**: Interactive Pune region map with pulsing AQI dispersion halos, wind-drift plumes, and live MQTT packet flow.
- **Sensor Sim**: Virtual ESP32 sensor controls (PM2.5, PM10, CO2, Temperature, Humidity, Packet Loss) and event presets.
- **Cloud Logs**: Simulated MQTT JSON stream, threshold alert engine, and CSV export.
